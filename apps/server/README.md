# AOA API service

Run `npm install` at repository root, then `npm run dev`. `npm run check -w @aoa/server` checks types and `npm test -w @aoa/server` runs authenticated HTTP integration tests and subtitle timing tests. Production runs TypeScript through the production `tsx` dependency; the shared package exports TypeScript source deliberately. Requires Node 22+ and the bundled `assets/fonts/NotoSansArabic-Regular.ttf`. Sharp uses Pango/HarfBuzz and explicitly loads that font to render Arabic PNGs.

The service loads the private repository-root `.env` when present; deployment environment variables work without that file. Never commit credentials. Required in both modes: `ADMIN_KEY` (at least 24 characters), `ASSET_SIGNING_KEY` (at least 32). Use independently generated random values. `DEMO_MODE=true` is an explicit opt-in to fictional catalog fixtures and in-memory household state. It never connects to Supabase or falls back to demo after a production failure. Demo playback uses a public Big Buck Bunny sample video, with fictional catalog titles and demo captions.

Production additionally requires `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `XTREAM_URL` (provider base URL), `XTREAM_USERNAME`, `XTREAM_PASSWORD`. Apply `supabase/migrations/202611070001_initial.sql` once to the selected Supabase project. It creates private RLS-protected household and episode metadata tables and the private `aoa-private-assets` storage bucket. The service-role credential belongs only on this server. It is never returned to browsers or Roku. `ASSET_BUCKET` can override the bucket name after creating an equivalent private bucket. A single deployment represents one household. Run one API instance on the small hosting tier: durable state changes use compare-and-swap so concurrent requests cannot consume pairing codes twice or overwrite sessions.

Optional environment:

- `PUBLIC_URL`: externally reachable HTTPS service origin, required for signed assets to work on Roku. Default `http://localhost:3001`.
- `PORT` (default 3001), `HOST` (default `0.0.0.0`).
- `CORS_ORIGINS`: comma-separated allowed phone origins; default `http://localhost:5173`. No wildcard credentials.
- `FONT_PATH`: absolute alternate path to the bundled Arabic font.
- `POSTER_ALLOWED_HOSTS`: comma-separated exact image CDN hostnames used by your provider; the Xtream hostname is allowed automatically. Redirects and private/link-local addresses are rejected. Provider artwork on other hosts needs an explicit entry.
- `OPENSUBTITLES_API_KEY`, `OPENSUBTITLES_USERNAME`, `OPENSUBTITLES_PASSWORD`: official OpenSubtitles REST API credentials. Search requires the API key; downloads require an account. Missing credentials produce a clear 503. Provider quota exhaustion returns 429 and no silent selection or retry loop. Only English results are offered. Exact identity, season/episode and title/year matches determine suggestions; low-confidence results require an explicit user choice.
- `LOG_LEVEL`: default `info`. Request URL/body logging is disabled, credential headers redacted, and internal upstream errors are not sent to clients.

Enrollment: use `POST /api/v1/admin/enroll` with `X-Admin-Key` and `{ "name": "Living room" }`. Store its returned **device token** in Roku; never place the admin key on Roku. Enrolling a replacement revokes prior Roku tokens and pairing codes. Phones claim a six-digit code generated by an enrolled Roku; the code lasts five minutes, is rate limited and consumed atomically. Device tokens are random 256-bit secrets stored only as SHA-256 hashes. Revoke phones with the Roku token. Pairing supports at most 20 active phones.

Catalog refreshes every 24 hours or explicitly; independent top-level requests are fetched concurrently. Filtering and paging occur server-side and page size is bounded at 100. Episode metadata discovered from a series is persisted for subsequent playback after a process restart. No provider stream or raw poster URLs appear in catalog responses. Only Roku-authenticated playback resolution returns a provider URL. Assets are HMAC-signed capabilities valid for one hour, no Authorization header required; the private bucket itself is never public. Assets have a 10 MiB per-file limit, 64 MiB memory cache, 128 MiB durable cache, two concurrent render jobs and a bounded request queue. Durable cache eviction regenerates image assets on demand; subtitle URLs should be refreshed through playback resolution if an old cached asset was evicted.

Commands expire after 60 seconds. A new play allocates a session immediately and expires older queued commands; controls issued while it is queued bind that new session. Acknowledgements are idempotent and retain the first terminal result. Stale progress and status cannot overwrite a newer session. TV status becomes offline after 30 seconds without a heartbeat. Keep polling at the contract cadence; empty command polls never write household state. State retains 300 recent commands and 1000 progress entries to bound storage. The progress list includes unfinished playback and the next uncompleted episode after a completed one. Subtitle timing offsets are seconds, bounded to ±600 and applied to SRT timestamps, clamped at zero.

`Dockerfile` builds from the repository root: `docker build -f apps/server/Dockerfile -t aoa-api .`. Serve through an HTTPS reverse proxy. Do not expose Supabase keys, provider credentials or the admin key in a public web build. Production connectivity and account quotas require live provider/Supabase/OpenSubtitles credentials and are not exercised by demo tests.
